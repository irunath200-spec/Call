2. ผลการจับคู่อัตโนมัติ

แหล่งข้อมูลเวลา: รับ = AB, จัด = AC, รอส่ง = AD, ส่ง = AE ภายใต้หัวข้อเวลาจัดส่ง (มาตรฐาน 45 นาที) ตรวจตำแหน่งคอลัมน์ในเมนูก่อนบันทึก
สัดส่วนบิล: AK = จำนวนบิลรวม (ใช้คำนวณ), AL/AM = ภายใน 45 นาที/สัดส่วน, AN/AO = มากกว่า 45 นาที/สัดส่วน โดย AM/AO อ่านได้ทั้งเซลล์เปอร์เซ็นต์ Excel (เช่น 0.80 = 80%) และข้อความ 80% ส่วนจำนวนบิลรองรับเครื่องหมายคั่นหลักพัน เช่น 1,234 และขีด - ใน AK–AO หมายถึงไม่มีข้อมูล (ไม่นับใน AVG)
